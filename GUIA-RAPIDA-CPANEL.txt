  PASOS PARA INSTALAR EN CPANEL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASO 1: Crear Base de Datos en cPanel
   → cPanel → Bases de Datos MySQL
   → Crear BD: mesadeayuda
   → Crear usuario con contraseña segura
   → Asignar TODOS LOS PRIVILEGIOS al usuario
   → ANOTA: nombre BD, usuario, contraseña

PASO 2: Subir Archivos
   → cPanel → Administrador de Archivos
   → Ve a public_html (o subdirectorio deseado)
   → Comprime la carpeta "cpanel/" en ZIP
   → Sube el ZIP y extráelo
   → Asegúrate que index.html esté en la raíz

PASO 3: Ejecutar Instalador
   → Abre: https://tudominio.com/install.php
   → Paso 1: Clic en "Comenzar Instalación"
   → Paso 2: Ingresa datos de la BD
   → Paso 3: Clic en "Instalar Base de Datos"
   → Paso 4: Clic en "Ir al Sitio"

PASO 4: Acceder al Sistema
   → https://tudominio.com/
   → Clic en "Iniciar Sesión"
   → Usuario: admin / Contraseña: admin123

  PROBLEMAS COMUNES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Error de conexión a BD:
   → Verifica nombre completo (incluye prefijo cPanel)
   → Verifica usuario y contraseña
   → Host generalmente es: localhost

❌ Página en blanco:
   → Verifica versión PHP (mínimo 7.4)
   → Revisa log de errores en cPanel
   → Verifica que todos los archivos se subieron

❌ Error 404:
   → Verifica que .htaccess existe
   → Asegúrate que mod_rewrite está activo
