📋 Instrucciones para ver el sitio completo:

  1. Ejecuta el comando: npm run build
  2. Los archivos se generarán en la carpeta dist/
  3. Copia el contenido de dist/ a tu servidor web
  4. Accede al sitio desde tu navegador

🚀 Opciones para ver el sitio:

Opción 1: Servidor de desarrollo (Recomendado)

npm run dev
Luego abre: http://localhost:3000

Opción 2: XAMPP

  1. Copia la carpeta dist/ a C:\xampp\htdocs\mesadeayuda\
  2. Inicia Apache en XAMPP
  3. Abre: http://localhost/mesadeayuda/

Opción 3: Servidor Python (Simple)

cd dist && python -m http.server 8000
Luego abre: http://localhost:8000
